## 7. Critérios de Aderência e Desenvolvimento Técnico
As vagas devem ser avaliadas considerando:
1. **Match Imediato**: Vagas que exigem Power BI, Excel, SAP, análise de indicadores, processos operacionais/comerciais ou logística.
2. **Oportunidades de Desenvolvimento**: Vagas de BI/Analytics (Pleno, Júnior/Pleno ou Analista de Negócios) que ofereçam ambiente propício para aprofundamento em:
   - SQL
   - DAX e Modelagem de Dados (Star Schema)
   - Power Query / M
   - Python para Análise de Dados
   - Pipelines de ETL e Bancos de Dados
3. **Amplitude de Busca**: Não restringir a busca apenas ao cargo "Analista de Dados". Mapear cargos como *Analista de BI, Analista de Processos e Indicadores, Analista de Planejamento e Controle, Analista de Operações e Dados, Analista de Sales Ops / Inteligência Comercial e Analista de Supply Chain*.
